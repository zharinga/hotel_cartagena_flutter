# Carpeta de evidencias

Aquí se guardan las capturas y resultados de pruebas de la actividad
"Rediseño de `RoomsScreen` — Hotel Cartagena".

## Archivos esperados

| Archivo | Qué debe mostrar |
|---------|------------------|
| `01_original.png` | Pantalla original (versión base del repo) |
| `02_mejorada_resumen_filtro.png` | Versión mejorada: resumen superior y filtro |
| `03_mejorada_filtro_3a4.png` | Filtro "3–4" aplicado (solo Suites) |
| `04_mejorada_boton_reservar.png` | Botón "Reservar" en cada fila |
| `05_mejorada_reserva_precargada.png` | `ReserveScreen` abierto con el número ya cargado |
| `06_mejorada_estado_vacio.png` | Estado vacío con sugerencia |
| `07_pantalla_angosta.png` | Prueba de desbordes en ventana ~360 px |
| `PRUEBAS.md` | Registro de pruebas (tabla) |

## Cómo tomar las capturas

1. Ejecuta la app (`flutter run -d chrome` o en el emulador).
2. Inicia sesión y entra a **Consultar habitaciones**.
3. Captura cada estado indicado arriba.
4. Guarda las imágenes en esta carpeta con los nombres sugeridos.

> Las capturas son **evidencia complementaria**: el código en `lib/` es el
> producto que demuestra el funcionamiento.
